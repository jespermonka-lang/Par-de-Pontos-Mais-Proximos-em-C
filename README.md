# Par de Pontos Mais Próximos em 2D – Divisão e Conquista

## Sobre o projeto

O projeto consiste na implementação de um algoritmo em linguagem C para identificar o par de pontos mais próximos em um plano cartesiano, utilizando o paradigma de Divisão e Conquista.

O objetivo é estudar e aplicar técnicas de otimização de algoritmos, comparando a abordagem tradicional de força bruta com uma solução de menor complexidade computacional.

## Funcionalidades

- Leitura de coordenadas de pontos em duas dimensões.
- Cálculo da distância euclidiana.
- Ordenação de pontos pelos eixos X e Y.
- Divisão recursiva do conjunto de pontos.
- Identificação do par de pontos mais próximos.
- Validação com diferentes conjuntos de dados.
- Comparação entre força bruta e Divisão e Conquista.

## Análise de complexidade

- Força bruta: O(n²).
- Divisão e Conquista: O(n log n), na abordagem clássica estudada.
